# bb-gh-copilot

bb plugin `gh-copilot` (package `bb-plugin-gh-copilot`, not on npm) registering GitHub Copilot CLI as ACP provider `acp-gh-copilot`. TypeScript: `server.ts`, `app.tsx`, `src/`. Lint with `slicc-lint`. No comments in any file. Agent guidance lives only in this AGENTS.md (≤1000 characters); no CLAUDE.md. Unit tests stay in gitignored `test/unit/`, run only for changed code (100% diff coverage). Integration tests in `test/integration/` test behaviour through exported surfaces; every bug fix adds one. `dist/` is built by `bb plugin build .` and never committed. CI and releases run slicc-shared-web's pipeline from `ci.yml`: semantic-release tags `vX.Y.Z` from `main` and commits the version; conventional commits decide it. The marketplace entry (get-bb/marketplace `entries/gh-copilot.json`) tracks `^1.0.0`, so a major needs a marketplace PR. Never move or delete a tag. Use `/opt/homebrew/bin/gh` for writes.
